shld d[sp],d[sp+4],b[sp+8]

It's assembly Pseudo-code .

It's means as the same of assemmbly instruction "shld ?,?,?"

The Pseudo-code has two step;

Operation

mov t0,d[sp+4];mov t1,b[sp];shl t0,t1;add sp,2;mov [sp+4],t0;mov [sp],eflag

Example

0053a730 shld d[sp],d[sp+4],b[sp+8] (add sp,2) 00000000-00000000 0019fe00 [sp]=eflag,[sp+4]=hdword(00000000-00000000)

"0053a730":It is a address of Pseudo-code

"shld d[sp],d[sp+4],b[sp+8]":It is Pesudo-code

"(sub sp,2)":This is secong step,operate the "sp",for keep stack balance

"00000000-00000000":the qword "[sp]-[sp+4]"

"0019fe00":the value of "b[sp+8]",the size is "b",so the value is "00"

"[sp]=eflag,[sp+4]=hdword(00000000-00000000)":Results after implementation
