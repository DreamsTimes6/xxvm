shr d[sp],b[sp+4]

It's assembly Pseudo-code .

It's means as the same of assemmbly instruction "shr ?,?"

The Pseudo-code has two step;

Operation

mov t0,d[sp];mov t1,b[sp+4];shr t0,t1;sub sp,2;mov [sp+4],t0;mov [sp],eflag

Example

006b22be shr d[sp],b[sp+4] (sub sp,2) d[sp]=00000000 b[sp+4]=00000006 d[sp]=eflag,d[sp+4]=00000000

"00677f53":It is a address of Pseudo-code

"shr d[sp],b[sp+4]":It is Pesudo-code

"(sub sp,2)":This is secong step,operate the "sp",for keep stack balance

"d[sp]=00000000":it's a value ,the size of "[sp]" is dword,so the value is "00000000"

"b[sp+4]=00000006":it's a value ,the size of "[sp+4]" is dword,so the value is "00000006"

"d[sp]=eflag,d[sp+4]=00000000":it's a value of result,the size of "[sp+4]" is dword,so the value is "00217700"
