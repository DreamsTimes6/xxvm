push wreg

It's assembly Pseudo-code .

It's means as the same of assemmbly instruction "push reg"

Operation

sub sp,2 ;mov word ptr [sp],wreg

Example

006ea022 push wreg index=00000038 0019ff94

"006ea022":It is a address of Pseudo-code

"push wreg":It is Pesudo-code

"index=00000038":It is a index of virtual-register,also it's a identification

"0019ff94":it's the value of virtual-register.note,the size of "reg" is word,so the value is "ff94"
