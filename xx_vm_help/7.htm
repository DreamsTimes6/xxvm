pop breg

It's assembly Pseudo-code .

It's means as the same of assemmbly instruction "pop reg"

Operation

movzx wreg,byte ptr [sp] ; add sp,2

Example

007fa9b6 pop breg index=00000010 006b0f0b

"007fa9b6":It is a address of Pseudo-code

"pop breg":It is Pesudo-code

"index=00000010":It is a index of virtual-register,also it's a identification

"006b0f0b":it's the value of virtual-register.note,the size of "reg" is byte,so the value is "0b"
