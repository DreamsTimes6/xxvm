shl d[sp+4],b[sp]

It's assembly Pseudo-code .

It's means as the same of assemmbly instruction "shl ?,?"

The Pseudo-code has two step;

Operation

mov t0,d[sp+4];mov t1,b[sp];shl t0,t1;sub sp,2;mov [sp+4],t0;mov [sp],eflag

Example

00677f53 shl d[sp+4],b[sp] (sub sp,2) d[sp+4]=000042ee b[sp]=fffcc207 d[sp]=eflag,d[sp+4]=00217700

"00677f53":It is a address of Pseudo-code

"shl d[sp+4],b[sp]":It is Pesudo-code

"(sub sp,2)":This is secong step,operate the "sp",for keep stack balance

"d[sp+4]=000042ee":it's a value ,the size of "[sp+4]" is dword,so the value is "000042ee"

"b[sp]=fffcc207":it's a value ,the size of "[sp]" is dword,so the value is "fffcc207"

"d[sp]=eflag,d[sp+4]=00217700":it's a value of result,the size of "[sp+4]" is dword,so the value is "00217700"
