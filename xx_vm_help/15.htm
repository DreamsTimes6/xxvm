mov d[[sp]],d[sp+4]

It's assembly Pseudo-code .

It's means as the same of assemmbly instruction "mov ?,?"

The Pseudo-code has two step;

Operation

mov t0,[sp+4];mov t1,[sp];mov [t1],t0;add sp,8

Example

007b796e mov d[[sp]],d[sp+4] (add sp,8) [sp]=00000000 [[sp]]=[00000000] [sp+4]=0019ff48

"007b796e":It is a address of Pseudo-code

"mov d[[sp]],d[sp+4]": is Pesudo-code

"(add sp,8)":It is Pesudo-code

"[sp]=00000000":the size of "[sp]" is dword,so the value is "00000000"

"[[sp]]=[00000000]":the size of "[[sp]]" is dword,so the value is "00000000"

"[sp+4]=0019ff48":it's the value of result,the size of "[sp+4]" is dword,so the value is "0019ff48".Final,the opration is "mov [00000000],0019ff48".If the first value is "[00000000]",its segment is "FS" usually.so "mov fs:[0],0019ff48"
