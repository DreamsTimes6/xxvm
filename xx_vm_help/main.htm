xx_vm_release

VMP Virtual Code Analysis restore plug-in, you can automate the analysis of virtual code protected by VMP, provides a rich information of the log files, through the analysis of the log pseudocode, we can almost restore the original instructions. So as to achieve the purpose of analysis. At present we have developed ollydbg applicable plug-ins, we will also docking other mainstream debugger

websit: xxdisasm.com

NOTES 1

"index";It is a index of virtual-register,also it's a identification

"d";dword

"w";word

"b";byte

"~";not

"|";or

"&";and

"[]";value of pointer

"sp";virtual stack

"dreg";dword register,example "eax"

"wreg";word register,example "ax"

"breg";byte register,example "al"

"dconst";dword const,example "0x11223344"

"wconst";word const,example "0x1122"

"bconst";byte const,example "0x11"

"d[]";dword value of pointer

"w[]";word value of pointer

"b[]";byte value of pointer

"t0":Temporary register

"t1":Temporary register

NOTES 2

The smallest virtual-stack operation is word.Example "push breg",the size of reg is byte,but the sp will subtract 2.

Examples are extracted from log information
