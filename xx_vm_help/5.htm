pop dreg

It's assembly Pseudo-code .

It's means as the same of assemmbly instruction "pop reg"

Operation

mov dreg,dword ptr [sp] ; add sp,4

Example

007fa9b6 pop dreg index=00000010 006b0f0b

"007fa9b6":It is a address of Pseudo-code

"pop dreg":It is Pesudo-code

"index=00000010":It is a index of virtual-register,also it's a identification

"006b0f0b":it's the value of virtual-register.note,the size of "reg" is dword,so the value is "006b0f0b"
